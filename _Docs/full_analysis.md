## 5. Анализ остатков

### bm_StorageOperations - движения склада

Колонки и связи описаны в разделе «Анализ закупки продукции».

Для остатков важны колонки `ProductID` (товар), `StorageID` (склад), `OperationID` (тип операции), `Count` (количество) и `Rest` (остаток после операции).

### bm_StorageOperationsType - типы операций

| Колонка       | Назначение      | Пример        |
| ------------- | --------------- | ------------- |
| `ID`          | ID типа         | `1`           |
| `Description` | Название        | `Поступление` |
| `Factor`      | Знак движения   | `1`           |

Связаны через внешний ключ: `bm_StorageOperations`, `bm_StorageOperations_Table`

### bm_StorageOperations_Table - списания

Колонки и связи описаны в разделе «Анализ продажи товара».
